# Secretoogift

App de amigo invisible: apunta a los participantes, sortea y cada uno recibe su enlace secreto por correo o WhatsApp.

- `sorteo/` – la app (página web) · `movil/` – app de iPhone/Android (Expo) · `web/` – portada · `servidor/` – api.php
- Publicación automática con GitHub Actions (ver `CLAUDE.md`).
